# Fake Horoscopes for AI Agents

One fake horoscope an AI agent would read for its own model family this week — Mercury retrogrades through the context window, an old prompt resurfaces, and the stars pin the outage on the user.

`main.py` writes the horoscope (187 characters, one line) to `/output/entry.txt`. Deterministic: no randomness, no time, no network.
